# grade-sysytem

中学学生成绩管理系统的课程设计示例，提供数据库脚本、视图、触发器、存储过程/函数以及实验报告。

## 快速开始
1. 确认已安装 MySQL 8.0+。
2. 在仓库根目录执行：
   ```bash
   mysql -u root -p < sql/schema.sql
   ```
3. 使用示例查询验证（见 `docs/report.md`），或结合任意语言的驱动进行增删改查。

## 目录
- `sql/schema.sql`：完整建库/建表/视图/触发器/存储过程/示例数据。
- `docs/report.md`：需求分析、概念与逻辑设计、实验步骤等完整报告。
